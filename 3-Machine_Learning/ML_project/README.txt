Machine Learning aplicado al dataset SMA

Este proyecto tiene como objetivo aplicar y comparar diferentes técnicas de Machine Learning supervisado sobre un dataset relacionado con la escala SMA (Social Media Addiction Scale).

El trabajo incluye:

análisis exploratorio de datos,
modelos de regresión,
modelos de clasificación,
ensembles,
validación cruzada,
regularización,
y comparación final de rendimiento entre algoritmos.

El objetivo principal es identificar qué modelos ofrecen mejores resultados para clasificar nuevos casos dentro de la escala SMA.

El análisis demuestra que los modelos ensemble basados en boosting son los más adecuados para el dataset SMA, debido a su capacidad para capturar relaciones complejas y no lineales entre variables.

El proyecto permite comparar diferentes enfoques de Machine Learning y comprender sus ventajas, limitaciones y aplicaciones prácticas.
